# Single-Machine replacement CI evidence

Rendered figures for the single-Machine test deadline adjustment. The code PR contains only the test-helper change; this branch stores its supporting figures.

The distribution measures replacement-phase completion in 112 historical single-Machine cases from 26 builds, plus three later controller-confirmed deletions after a failed test. Later deletion is not a passing testcase.

The paired phase figure compares five outliers with same-build, same-strategy successful controls. Both sides end at controller-confirmed Machine deletion.
